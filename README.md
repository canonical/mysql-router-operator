## Details

This repository is a read-only partial mirror of https://github.com/canonical/mysql-router-operators

The purpose of this repository is to maintain compatibility with tooling that expects one charm per git repository and charmcraft.yaml located at the root of the git repository. This repository is maintained by [charmcraftlocal](https://github.com/canonical/charmcraftlocal) and [git-filter-repo](https://github.com/newren/git-filter-repo).

The contents of this repository before development, issues, and pull requests were migrated to https://github.com/canonical/mysql-router-operators can be viewed at  
https://github.com/canonical/mysql-router-operator/tree/archive  
or  
https://github.com/canonical/mysql-router-operators/tree/archive/machines
